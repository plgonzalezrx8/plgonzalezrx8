Senior Cybersecurity Operator, U.S. Coast Guard · Owner at [Blueforce Innovations](https://www.blueforceinnovations.com/)

## Start here

- **[proxmox-mcp](https://github.com/plgonzalezrx8/proxmox-mcp)**  
  A Docker-first MCP server for Proxmox VE. Read-only cluster inspection, VM/container operations, and explicit confirmation gates for mutations. **Alpha.**

- **[InfisicalMCP](https://github.com/plgonzalezrx8/InfisicalMCP)**  
  A FastMCP server for self-hosted Infisical, connecting agents to secrets, projects, environments, identities, and audit logs through its REST API.

- **[InfiniMind](https://github.com/plgonzalezrx8/InfiniMind)**  
  A memory sidecar for OpenClaw. A separate service and bridge plugin provide storage, recall, policy filtering, and LanceDB-backed persistence without modifying OpenClaw core.

- **[bluewebcrawler](https://github.com/plgonzalezrx8/bluewebcrawler)**  
  A TypeScript CLI that turns sites into Markdown. HTTP-first crawling with Playwright fallback for JavaScript-rendered pages, sitemap discovery, and robots.txt support.

- **[CredForge](https://github.com/plgonzalezrx8/CredForge)**  
  Python utilities for processing credential datasets: NTDS filtering, deduplication, format conversion, and password-pattern analysis for security work.

- **[Next-Gen-Rubber-Ducky-Ninja](https://github.com/plgonzalezrx8/Next-Gen-Rubber-Ducky-Ninja)**  
  A WinUI 3 / .NET 8 desktop toolkit for validating and encoding DuckyScript, with line-by-line error reporting. [Release v2.0.1](https://github.com/plgonzalezrx8/Next-Gen-Rubber-Ducky-Ninja/releases/tag/v2.0.1).
