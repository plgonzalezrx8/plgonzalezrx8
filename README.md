## What I'm Building

### MCP Servers for Real Infrastructure

Docker-first FastMCP servers that connect AI agents to production systems — with guarded writes, read-only modes, and explicit confirmation gates.

- **[InfisicalMCP](https://github.com/plgonzalezrx8/InfisicalMCP)** — Manage Infisical secrets, projects, environments, folders, identities, roles, and audit logs from an agent.
- **[proxmox-mcp](https://github.com/plgonzalezrx8/proxmox-mcp)** — Read-only cluster inspection, VM/container lifecycle, snapshots, migration, and guarded Proxmox API access.
- **[odoo-mcp](https://github.com/plgonzalezrx8/odoo-mcp)** — Odoo 19 JSON-2 integrations with CRM tool packs, resources, and guarded write operations.
- **[technitium-dns-MCP](https://github.com/plgonzalezrx8/technitium-dns-MCP)** — 116+ Technitium DNS tools with read-only deployment mode and tiered safety for mutations.
- **[EasyWebhook-MCP](https://github.com/plgonzalezrx8/EasyWebhook-MCP)** — Send webhooks to Discord, Slack, or any HTTP endpoint from MCP clients with `.env`-backed aliases.

### AI Agent Infrastructure

- **[InfiniMind](https://github.com/plgonzalezrx8/InfiniMind)** — A Docker-first memory sidecar for OpenClaw with a dedicated memory service and bridge plugin.
- **[OpenClaw-Skills](https://github.com/plgonzalezrx8/OpenClaw-Skills)** — Custom skills that extend OpenClaw with specialized commands and integrations.
- **[bluewebcrawler](https://github.com/plgonzalezrx8/bluewebcrawler)** — A Node + TypeScript crawler that maps a site and exports AI-ready markdown.
- **[lobsterhook](https://github.com/plgonzalezrx8/lobsterhook)** — Local-first email-to-webhook bridge built on Himalaya with SQLite state, retries, and dead-letter delivery.
- **[RustySymphony](https://github.com/plgonzalezrx8/RustySymphony)** — Rust daemon that polls Linear, spins up per-issue workspaces, and runs Codex app-server sessions against them.
- **[CodexBarWindows](https://github.com/plgonzalezrx8/CodexBarWindows)** — Native Windows system tray app for tracking AI provider usage limits and reset windows.

### Security & Offensive Tooling

- **[CredForge](https://github.com/plgonzalezrx8/CredForge)** — A credential processing and analysis toolkit for NTDS dumps, password files, and credential lists.
- **[Next-Gen-Rubber-Ducky-Ninja](https://github.com/plgonzalezrx8/Next-Gen-Rubber-Ducky-Ninja)** — A modern WinUI 3 and .NET 8 toolkit for testing, validating, and encoding DuckyScript payloads.
